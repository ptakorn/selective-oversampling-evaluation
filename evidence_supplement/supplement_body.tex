\section*{Supplementary Evidence}
This supplement reports existing fitted-model results. No new model fits were performed for these tables. Synthetic intervals use paired replications; benchmark comparisons use dataset means, not folds as independent observations.

Differences are Complete minus comparator. Each setting has 30 paired replications. Percentile intervals use 5000 paired bootstrap resamples. They are exploratory individual 95\% intervals, with no simultaneous-coverage or multiplicity-adjusted significance claim.
