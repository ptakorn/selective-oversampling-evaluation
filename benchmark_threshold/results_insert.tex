\subsubsection{Benchmark Decision-Threshold Control}
\label{subsec:benchmark_threshold_control}
The threshold control was extended to all six benchmarks, three classifiers, and both label conditions using the original outer and inner partitions. Classifier parameters remained those selected by default-rule inner G-mean. For each selected configuration, three inner models provided held-out validation scores. A common threshold maximized the mean of the three fold-specific validation G-means over distinct out-of-fold scores in descending order, with the first maximum retained. Validation labels were unchanged; injected corruption was restricted to fitting observations. The final model was refitted on the full outer training fold and evaluated with both decision rules. Test labels were not used for threshold selection.
All 1620 final models completed, yielding 3240 decision-rule evaluations. Default-rule G-mean values exactly reproduced the corresponding previous benchmark results. ROC-AUC and average precision were unchanged between rules because both used the same fitted model and scores.
