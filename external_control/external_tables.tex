\section*{External Hybrid-Method Follow-up}
This separate addendum uses E-numbered tables. The configured external method is SMOTE-ENN from imbalanced-learn 0.14.2. All differences are SMOTE-ENN minus comparator. Bootstrap intervals are individual exploratory 95\% intervals, not simultaneous intervals or adjusted hypothesis tests.
The experiment crosses Gaussian, moons and circles geometries with clean, dispersed and boundary-near label corruption, with 30 replications per setting. LR and RBF-SVM have fixed configurations. Each model is evaluated at its default rule and a threshold selected using independent trusted validation. Count denotes SMOTE matched to the number of synthetics surviving SMOTE-ENN. Count + retention additionally retains exactly the same original observations as SMOTE-ENN. The comparator synthetics receive no additional editing. Tables E1--E4 provide 5000-resample paired percentile intervals; E5--E8 provide metric means. Full settings, provenance and ranking intervals are in the accompanying code and CSV files.
